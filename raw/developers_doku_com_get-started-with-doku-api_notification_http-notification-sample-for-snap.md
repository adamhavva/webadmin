# HTTP Notification Sample for SNAP | API Reference

Source: https://developers.doku.com/get-started-with-doku-api/notification/http-notification-sample-for-snap

---

## Overview

DOKU sends HTTP POST notifications for payment events. This document covers both SNAP and Non-SNAP formats.

---

## SNAP Format

### Required Headers

| Header | Required | Description |
|--------|----------|-------------|
| `X-PARTNER-ID` | Yes | Merchant's client ID (max 32) |
| `X-EXTERNAL-ID` | Yes | Unique ID generated by DOKU (max 36) |
| `X-TIMESTAMP` | Yes | ISO 8601 format: `yyyy-MM-ddTHH:mm:ss+07:00` |
| `X-SIGNATURE` | Yes | HMAC-SHA512 signature |
| `CHANNEL-ID` | No | Default "DH" (Direct Hosting) |

### SNAP Payment Notification (E-Wallet, VA, etc.)

```json
{
  "originalPartnerReferenceNo": "INV-20210124-0001",
  "originalReferenceNo": "1234567890",
  "originalExternalId": "15022aab-444f-4b04-afa8-ddfce89432ec",
  "latestTransactionStatus": "00",
  "transactionStatusDesc": "SUCCESS",
  "amount": {
    "value": "50000.00",
    "currency": "IDR"
  },
  "additionalInfo": {
    "channelId": "OVO SNAP",
    "channel": "OVO",
    "paymentType": "SALE"
  }
}
```

### Transaction Status Codes (SNAP)

| Code | Meaning |
|------|---------|
| `00` | Success/Paid |
| `01` | Transaction accepted (pending) |
| `02` | Transaction being processed |
| `03` | Pending |
| `04` | Refunded |
| `05` | Expired |
| `06` | Failed/Rejected |

### Signature Verification (SNAP)

```
stringToSign = HTTP-METHOD:RELATIVE-URL:ACCESS-TOKEN:HEX(SHA256(requestBody)):TIMESTAMP
Signature = HMAC-SHA512(stringToSign, clientSecret)
```

## Non-SNAP Format (DOKU Checkout)

### Required Headers

| Header | Description |
|--------|-------------|
| `Client-Id` | Client ID from DOKU Back Office |
| `Request-Id` | Unique random string (max 128 chars) |
| `Request-Timestamp` | UTC timestamp in ISO8601 format |
| `Signature` | HMACSHA256 signature |

### Non-SNAP Virtual Account Notification

```json
{
  "service": { "id": "VIRTUAL_ACCOUNT" },
  "acquirer": { "id": "BCA" },
  "channel": { "id": "VIRTUAL_ACCOUNT_BCA" },
  "transaction": {
    "status": "SUCCESS",
    "date": "2021-01-27T03:24:23Z",
    "original_request_id": "15022aab-444f-4b04-afa8-ddfce89432ec"
  },
  "order": {
    "invoice_number": "INV-20210124-0001",
    "amount": 150000
  },
  "virtual_account_info": {
    "virtual_account_number": "1900600000000046"
  }
}
```

### Non-SNAP QRIS Notification

```json
{
  "service": { "id": "QRIS", "name": "QRIS" },
  "acquirer": { "id": "DOKU", "name": "DOKU" },
  "channel": { "id": "QRIS_DOKU", "name": "QRIS-DOKU" },
  "order": {
    "invoice_number": "5ffa5675bb114404a4e426241cf05be0",
    "amount": 20000.00
  },
  "transaction": {
    "status": "SUCCESS",
    "date": "2025-06-20T04:26:26Z"
  },
  "emoney_payment": {
    "account_id": "1673637808",
    "approval_code": "234604941"
  }
}
```

### Non-SNAP E-Wallet (Shopeepay)

```json
{
  "service": { "id": "EMONEY" },
  "acquirer": { "id": "SHOPEE_PAY" },
  "channel": { "id": "EMONEY_SHOPEE_PAY" },
  "order": {
    "invoice_number": "INV-20210124-0001",
    "amount": 150000
  },
  "transaction": {
    "status": "SUCCESS",
    "date": "2021-07-09T02:06:14Z",
    "original_request_id": "24bb5232-3fe6-47a5-b0b0-d0fc3c6b5fdb"
  }
}
```

### Non-SNAP Transaction Status Values

| Status | Meaning |
|--------|---------|
| `SUCCESS` | Paid/Completed |
| `FAILED` | Failed |
| `PENDING` | Pending |
| `REFUNDED` | Refunded |
| `EXPIRED` | Expired |
| `CANCELLED` | Cancelled |

### Key Differences: SNAP vs Non-SNAP

| Field | SNAP Format | Non-SNAP Format |
|-------|------------|-----------------|
| Status field | `latestTransactionStatus` ("00", "03", etc.) | `transaction.status` ("SUCCESS", "FAILED") |
| Payment ID | `originalPartnerReferenceNo` | `order.invoice_number` |
| Amount | `amount.value` (string) | `order.amount` (number) |
| Transaction ref | `originalReferenceNo` | `transaction.original_request_id` |

### Signature Verification (Non-SNAP)

```
stringToSign = Client-Id:Request-Id:Request-Timestamp:Request-Target:Digest
Digest = SHA256(requestBody)
Signature = HMACSHA256(stringToSign, clientSecret)
```

---

## Response Format

DOKU expects HTTP 200 response:

```json
{
  "responseCode": "2007400",
  "responseMessage": "Successful"
}
```

---

## Notes

- DOKU may add new fields without notice - parse in non-strict format
- Always return HTTP 200 to acknowledge receipt
- Use idempotency keys to prevent duplicate processing
