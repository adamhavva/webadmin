## Gap Analysis vs ShopeeFood Mitra

### ⚠️ Yang Perlu Diperbaiki

1. **Polling vs Realtime WebSocket**
   - `RealtimeService.subscribeOrderPool()` pakai polling 5 detik
   - ShopeeFood Mitra pakai WebSocket/Firebase listener
   - **Fix:** Gunakan `onValue` listener bukan `Timer.periodic` di `OrderBloc._onSubscribeToOrders`

2. **Map Marker Bukan Avatar Real**
   - `BaristaMarker` pakai icon `Icons.delivery_dining`
   - ShopeeFood Mitra pakai avatar foto barista
   - **Fix:** Accept avatar URL di `BaristaMarker`, load dari `BaristaUser`

3. **Map Tidak Tampilkan Barista Lain**
   - Tidak ada fitur melihat barista lain di map (untuk customer)
   - Ini bagian customer app, bukan barista — fine

4. **Home Page Pakai Mock Data**
   - `_ordersToday = 12`, `_activeOrders` hardcoded
   - `TodayStatsCard` dan `ActiveOrderChip` pakai mock
   - **Fix:** Ambil dari `OrderBloc` atau `GET /api/orders`

5. **Peta Quick Action Belum Terintegrasi**
   - `Peta` di `_buildQuickActions` masih show SnackBar TODO
   - Seharusnya navigasi ke `/orders/:id/tracking` untuk order ACTIVE

6. **No Push Notification**
   - `PushNotificationService` ada di graph (community 33) tapi belum dipanggil saat order masuk
   - **Fix:** Trigger local notification saat `subscribeOrderPool` dapat order baru

### ✅ Yang Sudah Sesuai ShopeeFood Mitra

- Live map tracking dengan route polyline
- Bottom info card (customer + distance + ETA + action button)
- Tabbed order list (ASSIGNED / DELIVERING / ARRIVED / COMPLETED)
- Stok management dengan movement history
- Bottom sheet tab navigation
- Gradient AppBar di dashboard
- Status color coding (assigned=orange, delivering=blue, arrived=green)
- Profile dengan online toggle + logout
